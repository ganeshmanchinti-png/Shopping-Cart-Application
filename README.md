# 🛒 Shopping Cart Application

## 🚀 Live Demo
[Visit Shopping Cart Application](https://shopping-cart-application-2026.netlify.app)

## 📌 About the Project
The Shopping Cart Application is a full-stack web application developed using React.js and Node.js. Users can register, log in, browse products, and manage their shopping cart.

 ## ✨ Features

- User Registration
- User Login
- JWT Authentication
- Product Listing
- Add Products to Cart
- Manage Shopping Cart
- View Order Details
- Display Total Order Amount
- Order Summary
- Checkout Functionality
- Responsive User Interface
- REST API Integration

## 🛠️ Technologies Used

### Frontend
- React.js
- JavaScript
- HTML5
- CSS3

### Backend
- Node.js
- Express.js
- REST APIs
- JWT Authentication

### Database
- SQLite

### Deployment
- Netlify (Frontend)
- Render (Backend)
